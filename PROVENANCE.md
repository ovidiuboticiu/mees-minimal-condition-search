# Provenance and reconstruction notes

This repository was reconstructed on 2026-10-01 from the surviving project archive `Experiment_02.zip`.

The archive preserves frozen algorithm files, preregistration/freeze documents, METHOD-3 through METHOD-6 result summaries, EXT-3 result evidence, a builder-side validation report, publication audits, and an AI-assistance disclosure.

## Important distinction

The archive also preserves metadata referring to a more complete August 2026 reproducibility package (`MEES_Reproducibility_Package_v1.0.zip` / `MEES_Public_Repository_Ready_v1.0.zip`), but those complete ZIP packages are not present in the supplied archive.

Accordingly, this GitHub reconstruction does not silently recreate missing historical inputs or claim a fresh end-to-end reproduction. It preserves what is actually available and marks the limitation in `REPRODUCIBILITY.md`.

## Integrity policy

- Negative findings are retained.
- Historical PASS/FAIL verdicts are not rewritten.
- Stronger claims explicitly rejected in the frozen release record remain rejected.
- No license or author metadata is invented.
